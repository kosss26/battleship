# Regent fleet collection

Regent is a released cosmetic collection, available individually through the regular shop or as a complete set at `/fleet/regent`. Prices: ships 600 gems, waters 450, salvo 250, avatar frame 180; complete ownership costs 1480 gems. The complete-set purchase charges only for missing items, in one existing player transaction. Equipping the complete set is a separate atomic action. Neither purchase grants combat advantages.

The public showroom compares four separately illustrated classes with ordinary ships: Sovereign battleship, Viscount heavy cruiser, Corsair destroyer and Sentinel armoured launch. The same transparent 448 KB WebP atlas renders the showroom and actual boards. Nested crop viewports preserve their own dimensions, eliminating neighbouring sprite rows; heavy drop shadows were removed from ship previews.

Regent Sound uses a 36 KB sea texture, brass survey points, etched coordinates and a restrained metal frame. Regent Salvo provides steel-tipped shells, warm flashes, metal fragments, smoke, a silver water plume, rings, foam and a whole-hull sinking wake. Persistent hit, miss and wreck marks remain legible with reduced motion. The 300 ms flight and 1400 ms impact lifetime match all other cosmetics.

The Order of Regent avatar frame has brass rings, laurels and a crown. Owners can equip it normally in every game mode. The public profiles of opponents include only cosmetic identifiers, never hidden layouts. The enemy board defaults to the opponent’s cosmetics; an Appearance choice can show your set instead. Effects belong to the shooter. Battle results keep the universal Battleship interface.

An optional free AI trial remains available before purchase. The server limits the cosmetic override to this trial, disables consumable boosters and awards no ownership, progress, rewards, match statistics or history entries. Both trial seats demonstrate the complete set; a rematch remains a trial. Ordinary games using purchased Regent items have all normal rewards and statistics.

See [RELEASE.md](RELEASE.md) for production installation, release checks and server-access limitations. Existing collections and ownership remain unchanged.
