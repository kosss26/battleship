# Основная версия игры

Основная ветка поставки — `release/production`. Она содержит текущий морской интерфейс, кампанию, друзей, достижения, надёжное сохранение боёв и начислений, общий экран итогов, выбор оформления соперника, полноэкранный запуск Telegram и коллекцию «Регент». Ветка `main` относится к другой истории проекта и не перезаписывается. Серверные патчи HOSTKEY присоединяются при сборке в отдельном worktree.

## Установка на существующий VPS

В SSH-консоли сервера выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/kosss26/battleship/release/production/scripts/server-version.sh -o /root/battleship-version.sh.new &&
bash -n /root/battleship-version.sh.new &&
mv /root/battleship-version.sh.new /root/battleship-version.sh &&
bash /root/battleship-version.sh release
```

Команда `release` получает `release/production`, сохраняет резервную копию PostgreSQL и собирает основной backend и frontend. Она сохраняет исходный checkout HOSTKEY и его конфигурацию. Контейнер базы и его том не пересоздаются. После health check интерфейс переключается атомарно; при ошибке запуска возвращаются предыдущий образ и интерфейс. Обновление backend вызывает краткое переподключение клиентов; сохранённые партии восстанавливаются штатным механизмом.

Проверка:

```bash
bash /root/battleship-version.sh status
```

Ожидается `ОСНОВНАЯ ВЕРСИЯ` и коммит релиза. После первой успешной команды `release` обычный `deploy` также обновляет `release/production`. Явная команда `test` по-прежнему переключает тестовую ветку. Команда `original` возвращает сохранённую первоначальную версию, не откатывая базу. Снимки оригинала и теста не перезаписываются релизом.

## «Регент» в магазине

| Предмет | Кристаллы |
|---|---:|
| Флот «Регент» | 600 |
| Поле «Глубины Регента» | 450 |
| Эффект «Залп Регента» | 250 |
| Рамка «Орден Регента» | 180 |
| Все четыре предмета | 1480 |

Каждый предмет доступен отдельно в соответствующем разделе коллекции. Витрина `/fleet/regent` предлагает покупку всех недостающих частей одной транзакцией и отдельное действие экипировки комплекта. При частичном владении цена равна сумме только недостающих частей. Покупка не экипирует предметы автоматически; повторная покупка полного комплекта отклоняется без списания. Цены и владение проверяются сервером под блокировкой игрока, поэтому параллельные запросы не списывают оплату дважды.

Купленные предметы действуют во всех обычных режимах и показываются сопернику. Награды, рейтинг и статистика обычных боёв сохраняются. Бесплатная примерка остаётся изолированным боем против ИИ без наград и статистики; она не выдаёт предметы в собственность. Старые цены, предметы, баланс и прогресс сохраняются. Миграция или раздача коллекции существующим аккаунтам не требуется.

## Проверки и границы

Проверки охватывают покупки отдельных предметов и неполного комплекта, отсутствие частичного списания при нехватке валюты, конкурентную повторную покупку через настоящий HTTP API, экипировку, обычный бой с наградами и бесплатную примерку. Отдельно проверяются полноэкранный запрос, безопасные отступы, оформление двух разных игроков, сборка приложения и переключатель основного релиза с откатом при ошибке.

Публикация ветки сама по себе не устанавливает приложение на VPS. В этой сессии нет серверных SSH-ключей; активация происходит при выполнении приведённой команды оператором. Реальные Telegram Stars и сообщения пользователям в проверках не используются.

Проверка текущего релиза: 62 серверных теста прошли; сборка frontend, синтаксис Bash и восемь проверок установки/отката прошли. Из 23 браузерных сценариев в общем прогоне прошли 22; проверка восстановления сети первоначально читала отдельную копию store из-за горячего обновления Vite. После чистого запуска dev-сервера оба сценария восстановления прошли. Все 23 сценария проверены, включая покупку «Регента», обычные награды, PvP, кампанию, друзей, удаление аккаунта и админ-панель. На живом VPS установка из этой сессии не выполнялась.

Обновление общих окон, сезона, аватаров и отображения достижений описано в [UI_CONSISTENCY.md](UI_CONSISTENCY.md). Оно сохраняет общий стиль игры и не меняет правила выдачи наград или покупки коллекций.
